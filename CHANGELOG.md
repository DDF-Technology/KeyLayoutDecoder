# Changelog

Le modifiche rilevanti sono documentate in questo file. Il progetto usa il
versionamento semantico.

## [1.0.0] - 2026-08-25

### Aggiunto

- conversione di log tastiera tramite layout Windows dichiarato;
- drag & drop e supporto a più file;
- output UTF-8 con BOM;
- gestione di modificatori, AltGr, dead key, Invio, Tab e Backspace;
- modalità silenziosa `--quiet`;
- build MSVC statica x64;
- esempio sintetico e workflow GitHub Actions.
